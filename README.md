# マウス電池残量

Logicool G PRO X SUPERLIGHTの電池残量をWindowsのタスクバー右端に表示する小さなアプリです。レシーバー経由で電池情報を読み取り、約30秒ごとに更新します。

## 起動方法

1. `起動.bat` をダブルクリックします。
2. 通知領域のアイコンに残量（例: `58%`）が表示されます。見当たらない場合は `^` を開いてください。

アイコンは `^` 内とタスクバーの間で移動できます。左クリックすると詳細カード、右クリックすると更新・Windows起動時の自動起動・終了メニューが開きます。

## 動作環境

- Windows 10 / 11
- Python 3.9以降（このPCではインストール済みです）
- Logicool G PRO X SUPERLIGHTとUSBレシーバー

追加のPythonパッケージ、管理者権限、G HUBは不要です。G HUBとの併用もできます。

## 電池情報の取得

HID++の電池情報を読み取り、G PRO X SUPERLIGHTで使われる `0x1004`（Unified Battery）を優先します。利用できない場合は `0x1000`、`0x1001`、HID++ 1.0の順に試します。読み取り専用で、マウス設定は変更しません。

別のデバイスの残量を誤表示しないよう、HID++で機種名とマウス種別を確認できた場合のみ読み取ります。機種名は実機で報告される `PRO X Wireless` などを対象とします。確認できない場合は新たな残量を表示せず、一時的に前回の値を維持することがあります。

電池情報の読み取りは1つの背景スレッドで行い、画面外クリックの監視は詳細カードやメニューの表示中だけ動作します。

## 困ったとき

- 残量が表示されない場合は、USBレシーバーとマウスの電源を確認し、マウスを動かしてから右クリックの「電池残量を更新」を選んでください。
- 一度だけ読み取りを確認するには、PowerShellでこのフォルダーを開き、`python -X utf8 gpw_battery.py --once -v` を実行します。
- 終了はアイコンの右クリックメニューから行えます。自動起動を有効にした場合、アンインストール前にチェックを外してください。
